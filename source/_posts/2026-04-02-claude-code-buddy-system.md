## 原文导读

Claude Code 悄悄地上线了 **宠物系统**！输入 `/buddy` 就能孵化你的专属仙人掌宠物，还有稀有度、属性、性格，真的就像宝可梦。

## 核心玩法

### 原理

- 你的 **User ID** 就是种子，基于 Mulberry32 随机决定你的宠物是什么：鸭子、蘑菇、猫头鹰、蜗牛、幽灵，还有**卡皮巴拉**！
- 稀有度：**独立概率**，稀有度越高基础属性越高，1% 就是 SSR 金卡。
- 属性：五种属性（调试能力、耐心、混乱、智慧、毒舌），每个宠物都有长短板
- 性格也会影响互动，真的可以和你玩起来

你每次改完配置，自动写到 `~/.claude.json`，**同一个账号在哪登录都是同一只宠物**，不存在骗氪，完全免费。

### 怎么玩

1. 安装完 Claude Code ，输入 `/buddy` 就能得到你的仙人掌宠物。没刷到 SSR 不满意？可以反复刷，只要你愿意，就能刷出金色传说！
