## 4. 【我们使用 Git 的 --author 标志阻止了 GitHub 仓库中的 AI 机器人垃圾邮件】(We stopped AI bot spam in our GitHub repo using Git's –author flag)

- **链接：** https://archestra.ai/blog/only-responsible-ai
- **得分：** 387 | **评论数：** 184

### 文章摘要

Archestra.ai 团队分享了他们如何通过利用 Git 的 `--author` 标志来识别和阻止 AI 生成的垃圾 PR（Pull Request）。他们认为"要求所有外部贡献者获得批准"应该是默认设置。

### 重要评论

> 这有一个被忽视的安全隐患。仓库的贡献者拥有更高的权限，例如避免 Fork PR 运行的批准要求。GitHub 在文档中警告：当只要求首次贡献者获得批准时（前两个设置），任何有一个提交或 PR 被合并到仓库的用户都不需要批准。恶意用户可以通过让维护者接受一个简单的打字错误或其他无害的更改来满足这一要求，无论是作为他们自己编写的 PR 的一部分，还是作为另一个用户 PR 的一部分。

> 去他的 GitHub 让这种事情发生。如果他们实施了一些非常基本的评论和打开 PR 的要求，我们就不会在这里了。另外请让我们可以像删除 issue 一样删除 PR。

> PR 垃圾邮件对于运行赏金的仓库来说是一个大问题。也许 GitHub 应该暂时阻止那些 95% 以上的 PR 都被拒绝的账户创建 PR。

> GitHub 没有阻止 AI 的动力。这就像要求一家广告公司在他们的浏览器中内置广告拦截器一样。

## 7. 【实际上，民主死于人力资源】(Actually, democracy dies in H.R.)

- **链接：** https://www.nytimes.com/2026/05/18/world/americas/actually-democracy-dies-in-hr.html
- **得分：** 280 | **评论数：** 193

### 文章摘要

这篇纽约时报的文章基于新研究，探讨了平庸的员工如何帮助潜在的独裁者维持权力。研究发现，员工们为了职业发展（如恢复停滞的职业生涯或获得小幅晋升）的常见压力，足以促使中低级官员违反职业义务、基本规范甚至基本道德。这与汉娜·阿伦特提出的"平庸之恶"概念高度相关。

### 重要评论

> 结果发现，各地员工都熟悉的那种职业压力——想要恢复停滞的职业生涯或获得小幅晋升——足以促使中低级官员违反职业义务、基本规范甚至基本道德。我理解研究需要寻找可信的数据来推进，但这些结论与汉娜·阿伦特在《平庸之恶》中讲述的非常接近：普通公民试图获得晋升和推进他们的职业生涯，在这个过程中造成了无法估量的伤害，因为他们恰好在独裁统治期间工作。

> 我认为这是任何大型人群组织的产物。人类倾向于做对他们最有利的事情。大型组织设计者（政府、公司等）的挑战是如何设计一个系统，1）利用这种行为；即最大化雄心对系统的价值，2）不受这种行为的影响；即制衡。

> 我想起了 Karl Von Hammerstein-Equord 对军官的分类。本文中描述的人似乎属于"愚蠢但勤奋"的类别，这被归类为最危险的。

## 8. 【是时候放弃意识辩论引入的二元论了】(It is time to give up the dualism introduced by the debate on consciousness)

- **链接：** https://www.noemamag.com/there-is-no-hard-problem-of-consciousness/
- **得分：** 278 | **评论数：** 667

### 文章摘要

物理学家 Carlo Rovelli 在这篇文章中认为，我们需要从根本上将意识视为一种自然现象——尽管它极其复杂且知之甚少。他主张我们应该放弃哲学难题，专注于我们可以感知和推理的现实。意识是一个哲学发明（而且是一个狡猾的发明）。

### 重要评论

> Rovelli 正在论证（我认为）我们需要从根本上将意识视为一种自然现象——尽管它极其复杂且知之甚少。所以我们放弃哲学难题，专注于我们可以感知和推理的现实。问题是意识是一个哲学发明（而且是一个狡猾的发明）。

> 意识是基本现实；它是我们唯一可以确定的东西。我确定我正在感知什么。不管它是不是模拟：它仍然是我正在感知的东西。没有其他我可以确定的东西。

> 我从来没有完全理解我们所说的"意识"是什么意思，但我发现很有趣的是，大多数自称是唯物主义者/非宗教人士的现代哲学家可以在同一句话中争辩说，人类体验有一些特殊和超自然的东西。非此即彼：要么自然就是一切，因此意识是一种纯粹的自然现象，我们可以调查，可能最终复制，并且不能预先否认其他生物或机器拥有；要么在现实之外有一些我们可以称之为上帝的东西。

> 如果感受质（qualia）只是一种涌现属性，那么伦理就应该只是实现秩序或社会稳定等实际目的的一种手段。那么"在一个孤立的宇宙中，折磨一个能够体验感受质的生命是好的、坏的还是两者都不是？"这个问题的答案会是什么？我不能接受它是两者都不是。痛苦是负面的，即使我是个受虐狂，这对我来说也是显而易见的。如果你想更精确的话，苦难是负面的。

- **链接：** https://blog.cloudflare.com/cyber-frontier-models/
- **得分：** 267 | **评论数：** 100

### 文章摘要

Cloudflare 分享了他们使用 Mythos（一个专注于安全和漏洞发现的 AI 模型）的经验和见解。文章讨论了在规模上运行这项工作的四个教训：具体的窄请求比"发现漏洞"效果更好，需要适当的工具集成，对抗性审查很有价值，以及速度带来的挑战。

### 重要评论

> 这是什么意思？"这是一种做不同工作的不同工具，这使得与早期模型进行干净的苹果对苹果比较变得困难。"他们声称这是一种不同的工具，然后描述使用它的方式与你使用任何其他模型的方式相同。这真的感觉比一般的 Cloudflare 博客差很多，真的只是重复了 Mythos 公告，该公告已经指出关键部分是链接和制作示例。

> 大规模运行这项工作得出的"四个教训"让我笑了。四个中的三个本质上是相同的，而且完全显而易见。简而言之：具体的、窄的请求比"发现漏洞"效果更好。好吧，废话。

> 其他安全领导人对 Mythos Preview 最强烈的反应是关于速度——更快扫描、更快补丁、压缩响应周期。我们交谈过的不止一个团队现在正在执行从 CVE 发布到生产补丁的两小时 SLA。如果回归测试需要一天时间，你就不可能在不跳过它的情况下达到两小时 SLA，而跳过回归测试时发布的错误往往比你试图修补的错误更糟糕。

### 重要评论

> 这个周末我在我的旧 Thinkpad X40 上安装了 Haiku。它速度快，出奇地稳定。Emacs、VLC 运行得像个魅力。电脑对于网页浏览来说太慢了。BeProductive 办公套件是应用程序的杰作，9MB 下载；虽然不是开源的。然后我在 KVM/Qemu 下的 XPS13 上安装了 Haiku。一切都运行得飞快。我在考虑也许用那个安装来整理我的照片。BeFS 内置的元数据功能对此非常有用。我必须说我真的很印象深刻。

> Haiku 是优先考虑用户体验而不是基准测试的好例子。在引擎盖下，广义上讲，它在同一系统上的运行速度约为 Linux 的 60%。但在实际使用中，它感觉比其他任何东西都快得多。

> 我刚才在向我的后代解释，在乔布斯回来之前，苹果曾考虑收购 Be Inc.，然后他们允许自己被 NeXT 收购。有点有趣的完整循环：Be 将 BeOS 移植到 PowerMac，苹果没有收购 Be，Be Inc. 逐渐消失，HaikuOS 启动，20 多年后他们将 HaikuOS 移植到苹果硬件。

## 关于 Hacker News
